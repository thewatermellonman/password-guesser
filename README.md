# password-guesser
This is a program that tells you the strength of your password!
(and it's pink so it's much cooler)

It was made with html, css, and JavaScript.
<br>
## Score calculations
Using Javascript, the programe compares the user input to
a list of 10,000 common passwords.
<br>
Along with this, it checks for five main things: length, uppercase letters, lowercase letters, numbers, and symbols

The length requirement is worth 40 points, and the others are worth 15 points.
<br>

No passwords are stored, your passwords are safe!
